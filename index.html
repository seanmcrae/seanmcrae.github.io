04

2026 · Side project

PocketBrains: an on-device AI agent for iOS

  • 30.2% → 39.6% held-out accuracy
  • 24 tools
  • 0 cloud calls

Question. For people whose work can't go into a cloud chatbot, is an agent that never leaves the iPhone good enough to run their tasks, projects and notes?

What I built. A 24-tool agent that plans multi-step requests, acts on a local store, answers from notes with citations and can undo anything it did, on Apple's on-device model, an optional open model (MLX), or a deterministic fallback.

Outcome. End-to-end accuracy on a held-out set rose from 30.2% to 39.6%. The test set was frozen before tuning, and every number is published from CI.

What this shows. I still build, and I publish where my own work falls short, not just where it wins.

Building in public

Each project answers a product question, with tests and CI.

Technical enough to argue trade-offs with engineering and check the numbers myself. Every repo also documents where it fails.

ragbench

Which RAG setup should you ship under your cost and latency budget, and is its lift real or noise? Scores retrieval and agentic search pipelines.

agent-harness

Is a tool-using agent safe to give write access? Budgets, guardrails, human approvals, and scenario evals that fail CI.

llm-gateway

Does this request need your premium model? Routes each prompt to the cheapest model tier likely to answer it well.

credit-risk-explain

Which accounts should a team work this cycle? A calibrated risk queue with a reason code on every account and a fairness audit.

plg-metrics

Should we ship this experiment? Gives growth teams the answer with evidence, and refuses when the data is broken or the win is noise.

prd-to-backlog

Is this PRD ready for sprint planning? Turns it into a traceable backlog and flags requirements nobody can test yet.
